## 📦 Self-Host Installation

### Prerequisites
- Node.js **v18+**
- npm or yarn
- A WhatsApp account (for pairing)

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/Dexsam07/dex-tech-bot.git
cd dex-tech-bot

# 2. Install dependencies
npm install

# 3. Create .env file and add your session
echo "SESSION_ID=your_base64_session_here" > .env

# 4. Start the bot
npm start
```

For production deployment, use npm run start:pm2 (requires PM2 installed globally).
