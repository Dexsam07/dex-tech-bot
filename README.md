## 📦 Self-Host Installation

### Prerequisites
- Node.js **v18+** (Recommended: v20 LTS)
- npm or yarn
- A WhatsApp account (for pairing)

### Installation Steps

```bash
# 1. Clone the repository
git clone https://github.com/Dexsam07/dex-tech-bot.git
cd dex-tech-bot

# 2. Install dependencies
npm install --legacy-peer-deps

# 3. Create .env file
echo "SESSION_ID=your_base64_session_here" > .env
echo "OWNER_NUMBER=917384287404" >> .env
echo "PREFIX=." >> .env

# 4. Start the bot
npm start

# For production (PM2)
npm install -g pm2
npm run start:pm2
```

🧪 Troubleshooting

Issue Solution
SESSION_ID invalid Generate a fresh session from the pairing site.
Bot not responding Check internet and restart with npm run start:clean.
401 logged out Delete session/ folder and re-pair.
High memory usage Use npm run start:optimized.
File corruption Bot now uses atomic saves — update to latest version.
